# Веб-версия ИИ-консультанта: React + Django

Фронтенд — React (TypeScript, Vite), бэкенд — Django + Django REST framework. Логика ответа (поиск, агент,
проверки, карта ответственности, граф версий) — прежние модули из корня проекта, без изменений.

## Запуск (обычный)

Двойной щелчок по ярлыку «ИИ-консультант (веб)» или по `Запустить_веб-версию.cmd` в корне программы. Запускатель
`web/start_web.py`:

1. проверяет пакеты (предлагает установить `web/requirements.txt`);
2. запускает Ollama, если она не запущена;
3. применяет миграции базы; при первом запуске переносит данные прежней версии (учётные записи с прежними паролями,
   обращения, журналы, справочник);
4. запускает сервер waitress на http://127.0.0.1:8000 и открывает браузер. Окно «Сервер работает» — закройте его,
   чтобы остановить сервер.

## Доступ с других компьютеров сети

По умолчанию сервер доступен только на этом компьютере. Для сети (на компьютере-сервере):

```powershell
$env:WEB_HOST = "0.0.0.0"; $env:WEB_ALLOWED_HOSTS = "имя-компьютера,192.168.1.10"; python web\start_web.py
```

Сотрудники открывают `http://имя-компьютера:8000` в браузере. Для работы через интернет нужен HTTPS (обратный прокси),
это не настраивается автоматически.

## Разработка

```powershell
cd web\backend
python manage.py migrate
python manage.py runserver 127.0.0.1:8000
```

```powershell
cd web\frontend
npm install
npm run dev
```

Фронтенд в режиме разработки — http://localhost:5173 (запросы `/api` уходят в Django). Сборка для работы:
`npm run build` → `web/frontend/dist` (её отдаёт сам Django).

Тесты API (данные — копия во временной папке, Ollama не нужна):

```powershell
cd web\backend
python manage.py test core --settings=konsultant.test_settings
```

Перенос данных прежней версии вручную: `python manage.py import_legacy` (повторный запуск ничего не дублирует).

## Устройство

| Папка / файл | Что |
|---|---|
| `backend/konsultant/settings.py` | Настройки: путь к модулям агента, база SQLite в `data/konsultant.sqlite3`, сессии, CSRF, хешеры паролей |
| `backend/core/models.py` | Профиль (роль, ФИО), обращения, вопросы сотрудников, оценки, история, журнал, справочник |
| `backend/core/services.py` | Мост к прежним модулям: агент, база знаний, справочник, сводка, «Обработать новые» в фоне |
| `backend/core/views.py`, `urls.py` | API `/api/...` (JSON); права администратора проверяются в каждом изменяющем запросе |
| `backend/core/hashers.py` | Прежние хеши паролей (PBKDF2, соль hex) — вход с прежним паролем, затем перехеширование |
| `backend/core/management/commands/import_legacy.py` | Перенос данных из `data/*.json(l)` прежней версии |
| `backend/core/views_spa.py` | Отдача собранного React (`frontend/dist`) |
| `frontend/src/pages/*` | Экраны: Задать вопрос, Главная, Журнал вопросов, Сводка, Требует внимания, Документы базы, Сотрудники, История, Администрирование, Вход |
| `frontend/src/components/*` | Оболочка, ответ с источниками, окно документа, «Искать в», окна паролей |
| `start_web.py` | Запуск для пользователя |

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что |
|---|---|---|
| `WEB_HOST`, `WEB_PORT` | `127.0.0.1`, `8000` | Адрес и порт сервера |
| `WEB_ALLOWED_HOSTS` | `127.0.0.1,localhost` | Имена, по которым открывают сайт |
| `WEB_TRUSTED_ORIGINS` | — | Для HTTPS через прокси: `https://konsultant.company.ru` |
| `WEB_DB_FILE` | `data/konsultant.sqlite3` | Файл базы |
| `WEB_TIME_ZONE` | пояс этого компьютера | Часовой пояс дат (например, `Europe/Moscow`) |
| `DJANGO_SECRET_KEY` | создаётся в `data/secret_key.txt` | Ключ подписи сессий |

Остальные настройки (модель, база знаний, SMTP) — как в прежней версии, см. `README.md` в корне.
